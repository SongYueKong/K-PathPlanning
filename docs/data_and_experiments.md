# 数据可行性与实验设计

状态：全部是计划。尚未下载地理空间数据、构建真实路网或执行算法实验。

## 1. 案例选择顺序

优先核查两类候选：汶川震后受影响山区，以及 2015 年尼泊尔 Gorkha 地震受影响山区。它们仅是筛选候选，当前未确认任一地区具备满足本研究要求的完整公开数据组合。

先核查区域是否有清晰区分同震与后续滑坡的资料，再核查道路与封闭记录。不能因某场地震知名或滑坡清单规模大，就假定它适合次生灾害备用路线研究。

选定区域的必要条件：

1. 存在可构建有效道路图的几何与通行属性，且能说明其时间。
2. 至少具有灾害影响范围、发生时间或时间段，以及明确的来源/许可。
3. 能区分 t0 已知损毁和 t0 后用于验证的信息。
4. 初步确认区域有一定的可用替代通道；同时保留必经瓶颈作为困难实例。
5. 有独立验证信息，或能够明确把研究结论限制为灾害暴露代理而非实际通行。

## 3. 信息时序与泄漏控制

每个数据项需要 acquisition_time（采集时间）、event_time（事件时间）、release_time（可获取时间）与 planning_role（规划/验证）。时间未知时明确标注。

在 t0 建立 G0 时，只能使用当时已知的损毁。t0 之后的滑坡清单不得用于同一实例的风险拟合、风险分组校正或路线生成，然后又作为独立验证。

风险模型校准、路线规划和测试需要分离。优先按事件和区域划分；只有一场事件时采用空间留出与物理上合理的缓冲，并承认跨事件证据不足。不能只随机切分邻近路段。

当前道路图无法证明历史道路通达状态。若只有现今 OSM，则可研究“现今网络暴露于历史灾害形态”的情景分析，不能宣称还原了当年救援决策。若只有同震清单，则需要正式调整研究时间设定，不能冒称震后次生灾害验证。

## 4. 路网与风险表示的质量检查

- 投影到适当的米制坐标系，记录 CRS；不得用经纬度数值直接计算米制长度或缓冲。
- 检查真实交叉路口与桥上/桥下交叉，避免把几何相交一律视为连接。
- 保留并行道路的独立几何与风险信息，核查桥梁、隧道及方向限制。
- 划分断裂分量，解释道路端点吸附阈值，抽查规划路线是否沿真实道路。
- 滑坡面区分源区与完整影响范围；仅有点位时记录其不能支撑精细阻断结论。
- 对道路相交阈值、风险范围误差和DEM尺度做敏感性分析；不通过扩大缓冲人为制造本方法优势。
- 路网整理和风险拟合规则在查看测试结果之前确定。

## 5. 第一轮必须有的对照

| 方法 | 定义 | 比较目的 |
|---|---|---|
| B0：单条最短路径 | G0 中成本最低的路线 | 确认备用路线的增量价值 |
| B1：K 最短简单路径 | 同一绕行限制下最短的 K 条不同路线 | 对比仅追求低成本 |
| B2：成本最小的不相交路径组合 | 区分边/节点不相交；候选上求解或使用成熟算法 | 对比拓扑分离；不可行时如实报告 |
| B3：几何分散路线 | 用路线重叠/距离准则选取，调参只用训练资料 | 对比不含灾害机理的空间多样性 |
| B4：独立边失效下的路线组合 | 匹配训练估计的边际失效率，独立抽样每条边的状态；所有路线共享同一个边状态 | 隔离跨边空间相关性的作用；保留共享边本身造成的依赖 |
| B5：共享风险组/风险分散路线 | 根据同一风险单元信息进行风险组分离或暴露惩罚 | 检验本方案是否超越已有共同风险处理 |
| P：情景共同失效覆盖组合 | 使用全路网共同失效情景，最大化至少一条路线可用的覆盖 | 拟研究方法，尚无实现或结果 |
| Oracle：情景已知后的最短可用路线 | 每个情景重新规划，分别有/无绕行限制 | 只作为信息与可达性上界，不能部署 |

B5 的最终形式必须由最接近文献决定；不能自造一个明显较弱的版本替代已有方法。第一轮先共享候选集合比较选择目标，随后比较完整流程，并记录候选生成与组合求解的总时间。

不相交不可行时，不得私自放宽约束仍保留“不相交”名称。共同入口和必经瓶颈实例保留主报告；可以另分层展示，但不得因不利于方法而事后删除。

## 6. 三层实验

### E1：机制与求解检查

使用完全构造的小图，包含同一风险影响不同边、共同必经入口、区域全断和无灾害四类情况。枚举合法简单路径与路线组合，比较精确最优、标准贪心和候选限制；验证可达性上界。

这一层用于验证实现，不提供真实灾害效果证据。[数学定义](problem_formulation.md) 中的反例数值已通过独立计算检查。

### E2：真实路网上的受控压力实验

在同一路网上比较独立边失效、空间相关区域失效与风险单元失效。尽量匹配边际失效率及损毁强度，避免只让相关情景更严重。情景范围、相关尺度和参数使用训练资料确定。

测试情景独立生成，并使用不同空间形态或误差扰动。由本方法风险模型生成的测试只能证明模型条件下表现，不能替代 E3。

### E3：独立真实灾害资料

优先使用未参与规划的后续事件/区域和有时间记录的道路封闭。若仅有独立滑坡面，则按代理暴露指标报告；不将它提升为实际运输保障。

若事件样本不足，结果按案例报告，不用大量相邻起终点伪装成大量独立灾害样本。缺少关键独立验证时，顶刊定位须重新评估。

## 7. 指标与统计单位

主要指标为组合共同阻断率、至少一条路线可用率或情景覆盖率，以及相对单路径的绝对增量。明确哪个指标有真实概率意义、哪个只是压力情景表现。

同时报告最长路线与主路线绕行比、组合总长度、K_eff、求解时间、候选数、U_C/U_rho/U_inf、起终点原本不可达数及约束不可行数。

按相同起终点、相同灾害情景进行配对比较，事先确定主要比较 P–B5 与 P–B4。置信区间应尽量按事件/区域进行分组重采样；不同OD共享道路和同一灾害，不是独立样本。事件数量很少时承认区间和推广能力受限，不机械报告显著性。

不事先规定本方法必须提高某个百分比；效应大小和运行代价由真实结果决定。

## 8. 消融与先导预算

必要消融：跨边相关信息、地形/影响范围信息、风险定位误差、候选生成多样性、绕行约束与 K、DEM/灾害产品尺度。

先导预算建议：20–50 个预先选定的OD；K=1–5；rho=1.1/1.3/1.5；候选上限 M=100/500/1000 做逐级检查。合成情景可先用 10 个随机种子，训练和测试种子分离。数字是待调整的资源规划，不是已执行数量。

先运行小图与一个小区域，测量内存和求解耗时后决定真实区域规模。第一阶段不安装整套遥感/GIS环境，不启动大规模下载。
