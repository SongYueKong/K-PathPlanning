# 问题定义与方法边界

状态：数学方案初版。以下推导针对明确的模型假设，不代表灾害概率已获校准，也不构成算法创新性结论。

## 1. 输入与时间边界

以 G0=(V,E) 表示 t0 时刻可用的道路图。移除当时已知不可通行的道路，保留方向、道路几何、并行边、桥梁/隧道属性以及非负通行成本 c_e。

本阶段先以长度作为成本，避免无资料支持的灾后车速设定。如果能获得当时道路等级、车速或车辆限制，再单独开展时间成本分析。

一个实例包含起终点 (s,t)、路线预算 K、绕行系数 rho≥1，以及 t0 之后时间窗口 H 内的道路失效情景 Omega。c* 为 G0 中 s 到 t 的最短成本。如果起终点原本不可达，报告初始不可达，不计算该实例的绕行比。

风险单元 g 可以对应一个潜在滑坡影响范围或一组有机理依据的共同暴露路段。风险单元允许相互重叠。坡面上的滑坡起源位置不等于最终影响道路的范围，需要考虑运动路径、定位误差和道路脆弱性；没有相应资料时只建立代理情景。

## 2. 合法路线与共同失效

合法路线是简单 s–t 路径，满足 c(p)≤rho*c*。C_rho 为实际生成并去重的合法候选集合；它通常只是所有合法路线的子集。

对每个情景 omega，F_{e,omega}∈{0,1} 表示边 e 是否失效。情景应共同生成全路网的失效状态，而非分别对每条路线独立抽样：共享边必须共享状态，不同边也可能因同一灾害相关失效。

路线可用指示量为：

```
a[p, omega] = product over e in p of (1 - F[e, omega])
```

若桥梁、隧道入口或节点损毁能够阻断道路，可以统一映射为其关联边失效，记录映射规则并避免遗漏。a 的定义假定路线中任一必需路段失效即不可通行；部分容量损失另行建模。

## 3. 基础目标：至少一条备用路线可用

若情景权重 w_omega≥0 且总和为 1，路线组合 S 的可用性为：

```
R(S) = sum over omega of w[omega] * 1{some p in S has a[p, omega] = 1}
maximize R(S)
subject to S subset of C_rho, |S| <= K
```

组合共同阻断率为 1-R(S)。不能用“每条路线可用概率的独立乘积”计算共同阻断，因为独立性正是本研究要检验的假设。

只有当情景分布有适当的校准与时间窗口含义时，R 才可解释为该模型下的可用概率。人为压力情景的等权 R 应称为“情景覆盖率”，不能直接解释为真实发生概率。

先通过每条路线的绕行限制保证方案成本可接受，再在可用性相同的情况下优先选择成本较低的组合。不使用缺乏依据的距离与概率加权总分作为默认目标。

K 是上限。候选不足或额外路线没有覆盖收益时报告 K_eff、候选总数和边际收益。需要精确输出 K 条不同路线时，可在候选足够时补充合法路线并明确其零边际收益，不能重复路线或虚报保障提升。

## 4. 一个完全构造的反例

三条路线 A、B、C 在图上彼此边不相交。A 与 B 穿过同一山谷，C 经另一条通道。其成本分别为 10、11、13 个任意单位，rho=1.3，K=2。

| 构造情景 | 权重 | A 可用 | B 可用 | C 可用 |
|---|---:|---:|---:|---:|
| 无新增损毁 | 0.4 | 1 | 1 | 1 |
| 山谷共同失效 | 0.4 | 0 | 0 | 1 |
| C 通道失效 | 0.1 | 1 | 1 | 0 |
| 区域性阻断 | 0.1 | 0 | 0 | 0 |

最短两条路线 {A,B} 的覆盖率为 0.5；{A,C} 与 {B,C} 为 0.9。A、B 各自的覆盖率为 0.5，C 为 0.8。

这说明仅约束道路不重叠，不能排除共同灾害暴露。它不说明所有不相交路径算法一定选择 A、B，也不是任何真实案例的性能证据。示例权重完全人为构造。

## 5. 可达性上界与结构性风险

在每个情景下删除失效边，得到 G_omega。定义：

```
u_inf[omega] = 1{G_omega contains an s-t path}
u_rho[omega] = 1{shortest s-t cost in G_omega <= rho*c*}
U_inf = sum w[omega] * u_inf[omega]
U_rho = sum w[omega] * u_rho[omega]
R(S) <= U_rho <= U_inf
```

U_rho 是知道失效情景后还能重新选任意合法路线的上界；它不受预选 K 条路线限制，不能当作可部署算法比较。U_inf 则不受绕行限制。

还可以计算候选集合的上界 U_C=R(C_rho)，满足 R(S)≤U_C≤U_rho。U_rho-U_C 揭示候选遗漏，U_C-R(S) 反映 K 预算及组合求解造成的差距。差距不应全部归咎于优化器。

无向图可检查桥和关节点；有向道路图需要相应的有向可达性、支配关系或割集诊断。若唯一入口因某情景失效导致 G_omega 不可达，不能通过增加备用路线消除这个风险。应纳入主结果，不能事后删除此类不利起终点。

## 6. 基础求解与可声明的保证

对于固定候选、固定非负情景权重，R 是单调次模覆盖函数。新增路线 p 的收益是它在尚未被 S 覆盖的情景中新增的权重：

```
Delta(p | S) = sum w[omega] * a[p,omega]
              over scenarios where every q in S has a[q,omega] = 0
```

若 A⊆B，B 已覆盖情景至少与 A 一样多，因此 Delta(p|A)≥Delta(p|B)。由此可使用逐次选取最大新增覆盖路线的标准贪心方法。

在仅有 |S|≤K 约束、固定候选且准确计算收益的情况下，经典最大覆盖结果给出至少 (1-1/e) 的近似比，比较对象是该候选集合上的最优组合。这个经典保证不是拟提出的新理论；原始文献仍待核查引用。加入总成本预算、强制不相交或变化的权重后，不能原样沿用这一保证。

候选上精确比较可以采用整数规划。设 x_p 表示路线是否选取，y_omega 表示情景是否被覆盖：

```
maximize sum w[omega] * y[omega]
sum x[p] <= K
y[omega] <= sum a[p,omega]*x[p]
x[p], y[omega] binary
```

这只得到候选集合内的精确解，不是全路网全部合法路径上的精确解。小图枚举所有合法简单路径可验证两者的差别。

## 7. 候选集合不能只取最短 M 条

最短路径候选容易在同一通道附近聚集，使风险分散路线从一开始就没有进入比较。

候选生成拟采用多来源并集：K 最短简单路径、逐步边/节点惩罚、风险单元惩罚、可行的不相交路径，以及有限的情景绕行探索。所有候选回到同一原始路网核查合法性和成本并去重。

不同路线组合选择方法首先共享该候选集合，隔离选择目标的影响；之后再比较完整流程及各候选生成器的计算预算。增加 M 的敏感性、候选上界与小图完整枚举是必要检查。

Road MultiDiGraph 的并行边不能无依据地合并。NetworkX 的 shortest_simple_paths 不直接支持 MultiDiGraph；若后续用节点拆分或其他转换，需要保留每条原始边的几何与风险身份。第一阶段尚未选定实现。

## 8. 不确定权重的扩展边界

如果后续考虑权重不确定集合 Q，可定义 R_rob(S)=min_{w in Q} R_w(S)。但一般不能据此继承上述次模保证。

反例：两个情景，A 仅覆盖第一个、B 仅覆盖第二个；Q 包含分别把全部权重放在一个情景的两种分布。则 R_rob({A})=R_rob({B})=0，而 R_rob({A,B})=1，出现增加收益，违反次模性。

仅改变现有情景的权重也无法覆盖未进入支持集的新滑坡形态。因此，分布鲁棒扩展须独立研究求解与情景缺漏；当前默认先完成基础共同失效模型和独立压力验证。
