**修正早期判断：**ISPRS 的范围比“必须有新的遥感提取算法”更宽，明确涵盖空间信息建模和创新应用。显著的空间风险表示或建模方法也可能具备契合度；是否达到其贡献水平仍需相关论文和实际结果评估。

JAG 欢迎 GeoAI 不意味着本项目必须使用深度学习。ISPRS 的方法与应用范围也不意味着必须另造传感器或遥感分割模型。方法应由研究问题和可验证的数据需求决定。

## 2. 当前优先选择

保持 JAG 为优先评估目标，理由是目前研究重心为地球观测支撑的次生灾害风险与救援通达性决策。ISPRS 为并行比较目标：如果最终形成可推广的地理空间共同风险表示、空间误差传播或建模方法，而不仅是单一案例集成，则重新评估。

这属于当前方案判断，不是两刊硬性的分工或录用预测。期刊范围允许该主题，也不能替代新颖性、量化证据与文章质量核查。

## 3. 收紧后的研究主线

```
t0 可获得的地球观测与调查资料
  → 滑坡源区、影响范围与空间误差描述
  → 道路共同暴露及其不确定性
  → 至多 K 条备用路线组合
  → 独立灾害资料下的暴露/通达性与成本验证
```

建议工作题目更新为：**地球观测支撑的次生滑坡共同风险建模与救援备用路径组合规划**。

风险层和空间信息质量是重点待核查的贡献；经典覆盖优化作为决策环节。尚未证明这一完整链条区别于最接近工作，仍不能宣称首次提出。

地球观测数据可以来自可靠的现有影像产品、卫星/航空来源 DEM 或经核验的多时相清单；不要求全部从原始影像重新训练。但应说明其获取方式、时间、尺度、误差，以及它怎样改变风险判断和路线选择。仅把 DEM 用作地图底图不支撑这条贡献主线。

## 4. 必须区分的两种相关性

1. **真实灾害共同影响：**同一滑坡或运动范围使不同道路同时暴露或失效。它决定备用路线是否提供实际风险分散。
2. **地图误差空间相关性：**同一制图误差、配准偏差或 DEM 误差同时影响邻近风险估计。它影响我们对路线风险及其不确定性的估计，不等于实际灾害共同失效。

后续情景与消融应分别控制两者。不能用任意独立像元噪声代表完整空间误差，也不能把预测地图的相关误差当作已观察到的道路损毁关系。

## 5. 与期刊契合的验证任务

| 环节 | 待验证的内容 | 所需资料 |
|---|---|---|
| 灾害信息 | 影响范围、共同暴露或概率是否有独立支持 | 未参与拟合的滑坡范围、事件时间、制图质量说明 |
| 空间信息价值 | 地形/影像信息相对距离缓冲、易发性值与共享风险组基线是否有增量 | 强对照，统一资料和预算，尺度及定位误差实验 |
| 误差传播 | 考虑空间相关误差是否改变风险评估、路线选择与置信范围 | 有依据的误差模型、留出事件或独立资料；缺少校准时只称压力分析 |
| 决策效果 | 至少一条路线可用或未暴露的增量与绕行代价 | 独立道路封闭标签；没有标签时仅评价灾害暴露代理 |

核心实验必须包含撤去/替换地球观测信息、忽略灾害共同影响以及忽略空间相关误差的对照。只有下游路线指标好看，还不足以证明风险信息本身可靠。
