# K-PathPlanning：救灾环境下的备用路径组合研究

研究目标：考虑次生灾害造成的道路空间相关失效，为救援基地到受灾居民点选择至多 K 条备用路线，在限制绕行成本的同时提高至少一条路线可用的机会。

当前默认场景为震后山区次生滑坡，优先评估 JAG 的投稿契合度。研究区域、数据和创新性均待核查；尚无真实数据实验或投稿结论。
